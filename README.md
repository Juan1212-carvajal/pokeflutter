# 🧩 PokéFlutter

Aplicación móvil desarrollada en Flutter como proyecto final del Bootcamp de Flutter.

La aplicación consume la API de Pokémon y permite explorar información de los diferentes Pokémon, visualizar sus detalles y gestionar una lista de favoritos.

## ✨ Funcionalidades

- 📋 Listado de Pokémon.
- 🔍 Vista de detalle de cada Pokémon.
- ⭐ Gestión de favoritos.
- 🌐 Consumo de servicios REST.
- 📱 Interfaz desarrollada con Flutter.
- 🎨 Diseño responsive para dispositivos móviles.

## 🚀 Tecnologías utilizadas

- Flutter
- Dart
- HTTP Client
- REST API (PokéAPI)
- Gestión de estado Flutter

## 📦 Instalación

Clona el repositorio:

```bash
git clone git@github.com:Juan1212-carvajal/pokeflutter.git
```

Ingresa al proyecto:

```bash
cd pokeflutter
```

Instala las dependencias:

```bash
flutter pub get
```

Ejecuta la aplicación:

```bash
flutter run
```
